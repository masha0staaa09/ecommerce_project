# E-commerce Project
## Описание проекта
Проект представляет собой начальную реализацию системы управления товарами и категориями интернет-магазина на Python.

## Реализованный функционал
### Класс Product
Класс для представления товара. Содержит следующие атрибуты:
- name — название товара;
- description — описание товара;
- price — цена товара;
- quantity — количество товара в наличии.
### Класс Category
Класс для представления категории товаров. Содержит следующие атрибуты:
- name — название категории;
- description — описание категории;
- products — список товаров, входящих в категорию.

Также класс Category содержит два атрибута класса:
- category_count — общее количество созданных категорий;
- product_count — общее количество товаров, добавленных в категории.

- Счётчики автоматически обновляются при создании объектов категории.
## Тестирование
Для проверки корректности работы классов используются автоматические тесты с помощью pytest.

Тесты проверяют:
- инициализацию объектов Product;
- инициализацию объектов Category;
- корректность сохранения атрибутов объектов;
- количество товаров в категории;
- автоматическое обновление счётчиков категорий и товаров;
- создание пустой категории.

Для проверки стиля кода используется flake8, а для измерения покрытия кода тестами — pytest-cov.
## Используемые технологии
- Python
- pytest
- pytest-cov
- flake8
- Poetry
## Запуск тестов
Для запуска тестов выполните команду:
`poetry run pytest`

Для запуска тестов с проверкой покрытия кода:
`poetry run pytest --cov=src --cov-report=term-missing --cov-report=html`

Для проверки стиля кода:
`poetry run flake8 src tests`

После формирования HTML-отчёт о покрытии тестами будет доступен в папке htmlcov.
